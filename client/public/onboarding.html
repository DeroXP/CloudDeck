CloudDeck Setup

Step 1 of 6 — Admin Account

Create admin account

These are the credentials you'll use to sign in. Pick something memorable but strong — this account can launch games, control the PC, and create guest accounts.

Install the PC agent

The agent runs on your gaming PC and connects back to this Railway app over WebSocket. It accepts commands (launch games, fetch library, etc.) and pushes telemetry.

On your gaming PC, clone the repo, copy .env.example to agent/.env, set RAILWAY_WS_URL and AGENT_TOKEN, then run:

cd agent && npm install && npm run install-service

Waiting for agent to connect…

Install Sunshine

Sunshine handles the actual video stream. Install it on the same PC as the agent:

app.lizardbyte.dev/Sunshine

Default port is 47990 (config web) and 47989 (stream). The agent will detect it automatically.

Checking Sunshine via the agent…

Raspberry Pi (optional)

The Pi lets you wake the PC remotely. If you don't have one, skip this — you can always add it later. The PC must already be on for CloudDeck to be useful without it.

Set PI_URL and PI_SECRET_TOKEN in this app's .env, install the Pi script per the README, then test:

Click "Test Pi" to verify reachability

BIOS Wake-on-LAN

For wake-on-LAN to work, your gaming PC needs:

  • BIOS → Network adapter → Wake-on-LAN enabled
  • Windows → Device Manager → NIC → Power Management → "Allow this device to wake the computer" checked
  • "Only allow magic packet to wake the computer" checked

Try sleeping the PC, then click "Wake & test" — it should boot within ~30 seconds.

You're ready

Setup is complete. The wizard won't appear again unless you reset configuration from Settings.

If something didn't work, you can always revisit the README for troubleshooting.
